## 📲 Cómo agregar este repositorio

1. Abre **F-Droid** en tu dispositivo Android
2. Ve a **Ajustes → Repositorios de aplicaciones**
3. Toca el botón **+**
4. Pega esta dirección:
   > `https://dcg0.github.io/dclab-fdroid-repo/repo`
5. Toca **Añadir** ✅
